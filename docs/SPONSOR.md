# 支持 PokeClaw

如果这个项目对你有帮助，欢迎赞助。所有款项用于：

- 服务器、域名等基础设施
- 真机测试设备维护
- 持续开发时间

## 微信支付

国内用户直接扫码：

![微信收款码](sponsor-qr.jpg)

> 在 App 内：设置 → 关于 → **赞助**，会直接弹出这个收款码，无需联网、无需跳出到浏览器。
> 应用把同一张图打包在 `assets/sponsor-qr.jpg`（与本文件同图，轮换收款码时两处需同步）。
> 之所以不用跳网页：把二维码放在 Markdown 文件里，依赖浏览器渲染 Markdown **且**
> GitHub 把相对图片路径改写成 `blob/` 链接——Comet 浏览器两条都不满足，结果用户看到的是
> Markdown 源码而不是收款码。走浏览器看二维码本身就是个脆弱设计。

资金进入微信零钱，由维护者手动提现到银行卡。收款码不含姓名、头像等个人信息，赞助完全匿名。

## 其他方式
